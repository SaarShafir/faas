Registry

Declarations from git, joined against the consumer groups actually running. The console never edits these — §8's "one PR and zero infra tickets" only holds while function.yaml is the single source of truth, and a UI that could change it would be a second one.

This is a stopgap, and it should be replaced. §7 needs a registry of active functions for the aggregator to know the expected set, and §10 needs every (function, version) that ever ran so erasure can tombstone all of them. This page derives both from what is running right now, and consumer groups expire — so the historical half is wrong the moment a version is retired. Deriving it is not the same as keeping it, and only the latter satisfies §10.
